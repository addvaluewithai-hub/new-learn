# New Learn

بداية مستقلة للمنصة الجديدة، مع محرك React/Remotion مشترك وصفحة معاينة تطوير.
صفحات الحسابات تستخدم Neon Auth، والفهرس يُقرأ من جداول مستقلة على فرع Neon جديد.
التسجيل والجلسة والفهرس وفتح الدرس اتفحصوا على الموقع المنشور بنجاح؛ التفاصيل في docs/account-delivery.md.

## التشغيل

Node.js 24 وnpm. معاينة الدرس مستقلة؛ فهرس الحسابات يحتاج إعداد DATABASE_URL محليًا.

```bash
npm ci
npm run dev
```

افتح http://localhost:5173 لصفحات الحسابات. `?preview=chemistry` يعرض درس المراجعة: 11 مشهدًا و4 أسئلة.
الصوت والصور مثبتة داخل فولدر الدرس، تُفحص بـSHA256 وتُجهز أثناء البناء، ثم تُخدم محليًا.
المعاينة لا تعني اعتماد الدرس من جديد. `?preview=probe` يفتح اختبار المحرك بالنغمات.
أول Play يبدأ بتفاعل المستخدم؛ بعدها الشرح والسؤال والتعقيب والتكملة تعمل بالتتابع.

## إضافة منهج من learn-curriculums

```bash
npm run content:import -- ../learn-curriculums/dist/platform/<course>   # بعد export:platform هناك
npm run content:sync -- --print                                         # الـSQL من غير اتصال
```

الدروس بتتنشر **بالكتابة أولًا** (درس قراءة: البورد والشرح المكتوب والأسئلة)، والصوت مرحلة لاحقة.
التفاصيل في docs/content-import.md، ومراجعة تجربة الطالب في docs/ux-audit.md.

## نشر Cloudflare Pages

Root directory: جذر الريبو. Build command: `npm run build`.
Build output directory: `dist`، وفيه `index.html` مباشرةً.
Node.js 24. لا تستخدم جذر حزمة SDK كمخرج للموقع.

## التحقق

```bash
npm run prepare:fixture
npm run format:check
npm run check
npm test
npm run build
npx playwright install chromium
npm run test:browser
```

الفحوص تشمل الحدود و300 سطر، الأنواع والبناء، انتقالات التشغيل، توقيت ظهور السؤال،
منع التعقيب قبل المحاولة، pause/seek، الانتقال التلقائي، تعطل الصوت وإعادة المحاولة،
وحدود العرض على 320/390px. CI يشغّلها ويحتفظ بصور المتصفح.
إذا لم يتوفر المتصفح، نجاح الاختبارات الوظيفية وحده لا يعني قبول التشغيل المرئي.

## حالة SDK الإنتاج

المحرك حزمة ESM/types/CSS بإصدار 0.5.0؛ ملف التثبيت وSHA256 تحت distributions.
واجهة المعاينة العامة LessonPreview تقبل lesson وregistry وlayout اختياريًا، ومعها onContext/onReady/suspended لمضيف المنصة.
لا تحمل معاينة الحسابات أو الحفظ، ولا تعتمد على نسخة محلية من Learn القديم.
ريبو learn-curriculums يستهلك الحزمة بإصدار/commit مثبت، ويحوّل مصادر learn-authoring
المتحقق من تسجيلاتها وتوقيتاتها إلى معاينة مؤقتة. المراجعة الفعلية والنشر منفصلان.

## آخر التحديثات

- **وضع الاستماع (من غير شاشة):** إعداد جوه أي درس قراءة. Nova بتقرا الدرس، وبترد على الأسئلة بصوتك
  من غير زرار، وبتقاطعها بكلمة نداء (بتتغير من الإعدادات) أو زرار السماعة. التفاصيل في docs/nova.md.
- **الكونيكتور (Claude وChatGPT):** المدرّس يوصّل الـAI بتاعه بـ`/mcp`، فيعمل كورسات ودروس وبوردات
  كمسودات في حسابه. المدرّس يتفرج عليها من `?draft=…`، ويكتب ملاحظات على أي خطوة، والـAI يصلّحها.
  التفاصيل وخطوات التشغيل في docs/connector.md.
- **البورد التفاعلي (v1):** المدرّس يعمل البورد HTML بالـAI بتاعه، ويشتغل معزول على موقع منفصل
  من غير نت. الطالب يحرّكه ويجاوب عليه، وكودنا هو اللي بيصحّح، وNova بتشوف هو عمل إيه.
  جرّبه من `?preview=board`، والتفاصيل في docs/boards.md.
- **كورسات جديدة:** «منهج المعرفة» (10 دروس) و«إزاي الذكاء الاصطناعي بيشتغل» (الدرس 1)، كدروس قراءة عادية.

## الخطة الجاية

الخطة الكاملة ومرتبة بالأهمية في **docs/roadmap.md**، وأي إيجنت لازم يقراها قبل ما يبدأ ميزة جديدة.
الهدف: أي حد يبني دروس تفاعلية بمساعد صوتي بالـClaude أو ChatGPT بتاعه، بأي لغة، وتكلفة الذكاء الاصطناعي علينا قريبة من صفر.

1. Connector لـClaude وChatGPT (MCP server جنب `/api`).
2. مناهج يعملها المستخدم بنفسه (دروس قراءة كمسودات منفصلة عن المحتوى المعتمد).
3. ملاحظات على كل مشهد و"صلّح الكل" من الـAI.
4. منطقة درس modular وبورد sandboxed (HTML وcanvas وReact وفيديو بالكود).
5. سوق مجتمعي للكورسات المجانية والمدفوعة.
6. وضع الأطفال، ثم الامتحانات، والنمو، ومميزات الطالب، وأدوات المؤلف.

الأساس اللي اتعمل: docs/architecture.md وdocs/migration.md وdocs/data-contract.md وdocs/account-delivery.md.
