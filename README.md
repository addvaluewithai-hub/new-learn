# New Learn

بداية مستقلة للمنصة الجديدة، مع محرك React/Remotion مشترك وصفحة معاينة تطوير.
صفحات الحسابات تستخدم Neon Auth، والفهرس يُقرأ من جداول مستقلة على فرع Neon جديد.
ربط الداتا بيز بالموقع المنشور يحتاج إضافة DATABASE_URL في Cloudflare؛ التفاصيل في docs/account-delivery.md.

## التشغيل

Node.js 24 وnpm. معاينة الدرس مستقلة؛ فهرس الحسابات يحتاج إعداد DATABASE_URL محليًا.

```bash
npm ci
npm run dev
```

افتح http://localhost:5173 لصفحات الحسابات. `?preview=chemistry` يعرض درس المراجعة: 11 مشهدًا و4 أسئلة.
الصوت والصور مثبتة داخل فولدر الدرس، تُفحص بـSHA256 وتُجهز أثناء البناء، ثم تُخدم محليًا.
المعاينة لا تعني اعتماد الدرس من جديد. `?preview=probe` يفتح اختبار المحرك بالنغمات.
أول Play يبدأ بتفاعل المستخدم؛ بعدها الشرح والسؤال والتعقيب والتكملة تعمل بالتتابع.

## مكان كل شيء

| المسار                  | المسؤولية                                            |

| apps/platform           | الواجهة، الحسابات، API الفهرس ومضيف صفحة الدرس       |
| packages/lesson-runtime | عقد الحزمة، حالة التشغيل، التوقيت، المشاهد والمعاينة |

| tools                   | توليد الصوت التجريبي وفحص الحدود وحجم الملفات        |
| tests                   | قبول السلوك في المتصفح؛ اختبارات المحرك داخل حزمتها  |
| docs                    | حدود المعمارية وحالة النقل والخطوات التالية          |

## نشر Cloudflare Pages

Root directory: جذر الريبو. Build command: `npm run build`.
Build output directory: `dist`، وفيه `index.html` مباشرةً.
Node.js 24. لا تستخدم جذر حزمة SDK كمخرج للموقع.

## التحقق

```bash
npm run prepare:fixture
npm run format:check
npm run check
npm test
npm run build
npx playwright install chromium
npm run test:browser
```

الفحوص تشمل الحدود و300 سطر، الأنواع والبناء، انتقالات التشغيل، توقيت ظهور السؤال،
منع التعقيب قبل المحاولة، pause/seek، الانتقال التلقائي، تعطل الصوت وإعادة المحاولة،
وحدود العرض على 320/390px. CI يشغّلها ويحتفظ بصور المتصفح.
إذا لم يتوفر المتصفح، نجاح الاختبارات الوظيفية وحده لا يعني قبول التشغيل المرئي.

## حالة SDK الإنتاج

المحرك حزمة ESM/types/CSS بإصدار 0.2.1؛ ملف التثبيت وSHA256 تحت distributions.
واجهة المعاينة العامة LessonPreview تقبل lesson وregistry وlayout اختياريًا.
لا تحمل معاينة الحسابات أو الحفظ، ولا تعتمد على نسخة محلية من Learn القديم.
ريبو learn-curriculums يستهلك الحزمة بإصدار/commit مثبت، ويحوّل مصادر learn-authoring
المتحقق من تسجيلاتها وتوقيتاتها إلى معاينة مؤقتة. المراجعة الفعلية والنشر منفصلان.

## ما بعد الأساس

قبول تسجيلات حقيقية ومراجعة الدروس ← الحسابات والفهرس الحقيقي ← التقدم والاستكمال
← استيراد واعتماد وإطلاق المناهج ← AI Chat وLive المساعد.
انظر docs/architecture.md وdocs/migration.md وdocs/data-contract.md وdocs/account-delivery.md.
